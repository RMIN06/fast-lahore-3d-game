# M7 — Interiors (block by block): accepted

Date: 2026-11-20. **M7 acceptance passed for all six blocks (F, D, C, B, A, E — each its own commit). M8 has not started.**

## Important: the layouts are generated placeholders

No floor plans exist in any source (PRD §7, OPEN_QUESTIONS #9–14). Following ARCHITECTURE §4, each interior is **generated** from the floor and room lists in `data/campus.json`.

- **From the data:** room identity (code, name, kind, floor), floor order and heights, and each block's footprint.
- **Generated:** every position, corridor, wall and stair. These are flagged as placeholders in the debug view.
- **Not changed:** `data/campus.json`. No room polygons or stair positions were written into it, so curated-mode validation still reports interiors as unknown, honestly. The generator runs at load time.

## What was built

| Item               | Implementation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Generator          | `src/systems/interior.ts` (pure TypeScript), per block: (1) a building frame along the footprint's longest edge; (2) the largest rectangle that fits inside the footprint; (3) a **vestibule** from the main entrance (M4 placeholder) into it; (4) an **entrance hall** holding the stair shaft; (5) per floor, a **corridor spine** with rooms in strips on both sides, or one side when the block is narrow, with a 1.4 m door to the corridor for each room. Rooms marked left or right in the data go on that side, in data `order`. Open-hall, parking and custom floors (F cafe and parking, D benches, the E Library) become one open room |
| Stairs             | One shaft per block with stacked straight ramps (about 29–30°, under the 40° climb limit) linking **every pair of adjacent floors**, basements included. Rails line the hall side, and the open ends work as landings. No lifts exist in the data                                                                                                                                                                                                                                                                                                                                                                                                  |
| Physics            | The facade gets a 3 m × 2.7 m **door opening** at the entrance (the rest stays solid). The ground mesh gets holes under the interiors so basements are reachable. Interior walls, floor slabs, the roof, rails and ramps are box colliders, with ramps as tilted boxes                                                                                                                                                                                                                                                                                                                                                                             |
| Door plates        | Room code and name drawn into one canvas texture atlas per block (no font download), on plates beside each door facing the corridor. One draw call per block                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Room labels        | The HUD location line, such as `F · New Building · 2nd Floor · NB-201`, comes from the player's position (`roomAt`, `floorAt`). The dev overlay can teleport to every room anchor                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Interior streaming | `src/game/Interiors.tsx`: a block's interior loads within 25 m of its door or while inside, and unloads beyond 60 m. Physics stays loaded (it is cheap)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Entry transitions  | Crossing the door threshold fades the screen briefly, hides that block's exterior shell, and switches to steady indoor lighting (GAMEPLAY_SPEC §4)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Doorways           | Dark door rectangles on the facades show where the entrances are                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Debug view         | With Confidence colors on, generated walls show red (placeholder) and room floors show their data confidence, such as estimated (yellow) or placeholder washrooms (red)                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

## Verification

- Typecheck, ESLint, unit tests (including 106 physics room walks), campus validation and the production build pass.
- The per-room e2e test for all six blocks passed in one run (8.8 min). The other e2e suites (player, registration, overview, time, tracer) also pass.
- The e2e tests run on the Low preset in an 800 × 450 viewport, because headless Chromium renders WebGL in software (indoors it ran at about 2–4 FPS at full size with shadows). The interior draw-call and triangle budgets do not depend on that. Real-hardware FPS remains unverified, as for earlier milestones.
