# M9 — Navmesh and NPCs: accepted

Date: 2026-11-20. **M9 acceptance passed. M10 has not started.**

## What was built

| Item                     | Implementation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Navmesh bake             | `npm run build:navmesh` (`scripts/build-navmesh.ts`) bakes **one multi-level navmesh** with recast-navigation from the same geometry the physics uses: the campus ground inside the boundary (minus basement holes), the Masjid and its gate path, every building, wall and interior collider (walls, floor slabs, stair ramps). Output: `public/navmesh/campus.bin` (about 226 KB) and `campus.json` with the input hash and the bake settings (cell 0.15 m, agent radius 0.3 m, height 1.8 m, climb 0.3 m, slope 40°)                                                    |
| Freshness check          | A unit test hashes the current navmesh input and compares it with `campus.json`. Any campus or interior change fails the test until the navmesh is re-baked                                                                                                                                                                                                                                                                                                                                                                                                                |
| Population and schedules | `src/systems/npc.ts`, pure and seeded (the same day always gives the same plans): **110 students** on weekdays (30% on Saturday, 5% on Sunday), **8 faculty** on weekdays, a **guard at every gate** around the clock, **2 cafe staff**, a **librarian**, a **medical officer** and a **shopkeeper per shop**. Students go gate → class in their department's block → cafe lunch (queue) → library (35%) or a second class → leave between 16:00 and 20:00. On Fridays most male students and faculty go to Jummah at the Masjid. Faculty: office → teach → office → leave |
| Simulation               | `src/systems/npc-sim.ts`. The **nearest ≤ 60** NPCs within 90 m are DetourCrowd agents with collision avoidance (the player is an obstacle agent too). Everyone else is simulated **abstractly** along the same navmesh path at walking speed, and becomes an agent as the player approaches. Agents caught in a head-on jam yield for 3 s (walking abstractly), then rejoin                                                                                                                                                                                               |
| Queues                   | Cafe counter and library desk. People join the back of the line, the front is served in 0.5 game minutes, and everyone moves up one place. Long lines fold into rows of 8, so they stay inside the room                                                                                                                                                                                                                                                                                                                                                                    |
| Time                     | Schedules use game time. Loading a save mid-day (or jumping the clock) places NPCs straight into their current activity instead of walking them all in from the gates                                                                                                                                                                                                                                                                                                                                                                                                      |
| Rendering                | `src/game/Npcs.tsx` loads the navmesh, runs the simulation and draws the nearest ≤ 60 NPCs with the M8 character. Each look (body, skin, hair, outfit) builds its LOD geometry once and NPCs share it, along with one material. Staff wear a colour per role. Only LOD0 casts shadows. Seated NPCs sit on a plain stool (one instanced draw call) until furniture exists                                                                                                                                                                                                   |
| Dev overlay              | NPC status and counts (present, active, drawn, stuck), plus a **Navmesh** toggle that draws the navmesh triangles                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## Known limits

- The navmesh also covers building roofs (flat collider tops). They are unreachable islands: targets snap only within ±0.4 m vertically, so no NPC is ever sent there.
- Opening hours, staff numbers and the student population are placeholders (OPEN_QUESTIONS #46).
- Fresh Friez is a street-side shop outside the wall, off the navmesh. Its shopkeeper stands at the counter and closes up at 20:00 rather than walking onto campus.
- NPCs sit on plain stools: there is no furniture yet (M13 props).
- In a time jump, NPCs already on campus carry on with their current activity and catch up with their schedule as they move.
