# M8 — Characters and animation: accepted (procedural placeholder characters)

Date: 2026-11-20. **M8 acceptance passed using procedural characters built in code (own work). M9 has not started.**

## Why procedural characters

MILESTONES says M8 _needs owner_ character models and animations (ASSET_PIPELINE §5). None exist in the repository. Downloading third-party models, even CC0 ones, needs the owner's explicit approval of a specific source.

So M8 delivers **own-work procedural characters**: a real skinned skeleton, rigid-skinned primitive parts and procedural animations. Owner glTF models can later replace the mesh and clips in the same `CharacterRig` slot (OPEN_QUESTIONS #45).

## What was built

| Item                     | Implementation                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Skeleton and proportions | `src/systems/character.ts`: 17 bones (hips, spine, chest, neck, head, arms, legs, feet). Male and female proportions come from the avatar heights (eyes at 1.65 m and 1.58 m, GAMEPLAY_SPEC §3; total height 1.75 m and 1.68 m). The female body has wider hips and narrower shoulders                                                                                                                                    |
| Animation set            | **idle** (breathing), **walk**, **run**, **jump**, **sit** (seat height 0.46 m), **kick** and **swing** (bat or racket), all procedural and pure TypeScript                                                                                                                                                                                                                                                               |
| No foot sliding          | Walk and run use two-bone **leg IK**. During stance each foot target moves backward exactly as far as the body moves forward, and the gait phase advances by the _distance actually moved_, so a planted foot stays planted at any speed. Swings use a Hermite curve, so the foot's ground speed is zero at lift-off and touchdown. Gait sizes are fitted to the leg's reach (with hip bounce), so the IK never stretches |
| State machine            | `CharacterAnimator`: idle, walk (above 0.25 m/s), run (above 3 m/s), jump (after more than 0.12 s airborne, so stairs and kerbs don't count), sit (held while requested), kick and swing (play to the end). 0.18 s cross-fades                                                                                                                                                                                            |
| Mesh and LODs            | `src/world/character-mesh.ts`: one merged **SkinnedMesh per LOD** (one draw call), all sharing one skeleton. **LOD0** has about 6,050 triangles (with eyes), **LOD1** about 1,880, **LOD2** about 630. They switch at 0, 12 and 35 m                                                                                                                                                                                      |
| Variants                 | Skin tone (4) and outfit colour (6) as vertex colours, plus trousers and shoes. Hair styles change the geometry: short, long, tied, and covered (a head covering, in a light scarf colour)                                                                                                                                                                                                                                |
| In game                  | The capsule placeholder is replaced. The character turns toward its movement and animates from real displacement (teleports don't count as motion). The dev overlay shows the animation state and has Sit, Kick and Swing buttons until seats (M10) and mini-games (M11) trigger them                                                                                                                                     |
| First person             | **Hidden-body policy** (one of the two options MILESTONES offers): the body is hidden in first person and shown in third person                                                                                                                                                                                                                                                                                           |
| Preview                  | Dev-only `/dev/characters` page: both avatars, every animation and each LOD with triangle counts                                                                                                                                                                                                                                                                                                                          |

## Acceptance

| Check (MILESTONES.md)                     | Result                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Both avatars play all required animations | Unit tests: for both bodies, all seven animations change the pose from idle, and the animated ones change over time. E2E preview: both bodies play each animation (pixels differ from idle; walk, run, kick and swing keep moving). E2E in game: the female avatar walks, runs, jumps, sits, kicks and swings, with each state shown live |
| No foot sliding beyond tolerance          | Unit test, for both bodies at walk (1.6 m/s) and run (4.8 m/s): a planted foot (within 3 mm of the ground) drifts **less than 1 cm** over two seconds of gait. Tolerance: 1 cm                                                                                                                                                            |
| 3 LODs                                    | Unit and e2e tests: three levels per body with strictly decreasing triangles, one skinned mesh (one draw call) per level and a shared skeleton                                                                                                                                                                                            |
| Asset licences logged                     | `docs/ASSET_LICENSES.md`: the procedural characters and animations are own work. No third-party assets were added                                                                                                                                                                                                                         |
