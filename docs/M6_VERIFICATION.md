# M6 — Registration, save, spawn, HUD shell: accepted

Date: 2026-11-20. **M6 acceptance passed. M7 has not started.**

## What was built

| Item                            | Implementation                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| App flow (PRD §5)               | Title, then Register, then Game (`src/state/app-store.ts`, `src/ui/TitleScreen.tsx`, `src/ui/RegisterScreen.tsx`). Continue loads the local save. The 3D world mounts only in the game and remounts for each new game or continue                                                                                                                                                                                                               |
| Registration (GAMEPLAY_SPEC §1) | Roll number (required, soft-checked against `^\d{2}L-\d{4}$`: it warns but never blocks). Optional display name. Department, taken from campus data. Avatar: male or female, 4 skin tones, 4 hair styles and 6 outfit colours, with a placeholder body preview at the real height. Everything stays in the browser                                                                                                                              |
| Spawn                           | `departmentSpawn()` reads the department's `spawnAnchor` from campus data. The four anchors now have positions 3 m outside their block's main entrance, facing it, marked `confidence: "placeholder"` (because the entrances are placeholders, OPEN_QUESTIONS #39). CS uses C; Civil uses B; EE and Management use D                                                                                                                            |
| Avatar in game                  | The capsule's height follows the body: eyes at 1.65 m (male) or 1.58 m (female), per GAMEPLAY_SPEC §3. Outfit-coloured body and a head in the chosen skin tone until the M8 models                                                                                                                                                                                                                                                              |
| Save (ARCHITECTURE §6)          | `src/systems/save.ts`: a Zod-validated, versioned save `{ version, profile, position+yaw, time {day, minutes}, settings, savedAt }` under the versioned key `fast-lahore.save.v2`. **v1** is the shape in ARCHITECTURE §6 (`timeOfDay` only). **v2** adds the weekday from M5. Migrations run step by step, a migrated legacy save is rewritten under the new key, and corrupt, unversioned, future or invalid saves fail safely with a message |
| Save triggers                   | Pause menu → Save; autosave every 60 s, when the page is hidden or closed, and on Exit to title. A new game saves immediately                                                                                                                                                                                                                                                                                                                   |
| Continue                        | Restores position and facing, weekday and time, settings and profile. The title screen shows a summary (name or roll number, department, day and time) and offers Delete save                                                                                                                                                                                                                                                                   |
| Pause menu (Esc)                | Resume, Save, Settings, Time controls, Exit to title. Game time pauses while it or Settings is open. Losing the mouse lock with the browser's own Esc also opens it                                                                                                                                                                                                                                                                             |
| Settings                        | Graphics preset (Low: no sun shadows, 1× resolution; Medium: 1024 shadows, up to 1.5×; High: 2048 shadows, up to 2×). Volume is saved, and used from M12                                                                                                                                                                                                                                                                                        |
| Phone (P)                       | Tabs: Map (live campus map with the player), plus stubs for Timetable, Messages and Tasks that say they arrive in M10, and a Settings shortcut                                                                                                                                                                                                                                                                                                  |
| Map (M)                         | Full-screen north-up campus map from campus data, with building names, gates and the player's position and facing                                                                                                                                                                                                                                                                                                                               |
| HUD                             | Time and weekday, speed, day type, a compass (heading and degrees), the player's name or roll number with an "active task" line, and key hints. The crosshair hides while an overlay is open                                                                                                                                                                                                                                                    |
| Input                           | Overlays switch input to the menu layer. T, P and M toggle their overlay, and Esc closes whichever is open                                                                                                                                                                                                                                                                                                                                      |
| Dev tools                       | A teleport-to-anchor list in the dev overlay (from ARCHITECTURE §8), also used by the e2e tests                                                                                                                                                                                                                                                                                                                                                 |
